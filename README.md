# HƯỚNG DẪN CÁCH SỬ DỤNG HIỆU QUẢ KHO LƯU TRỮ ThuatToan CỦA NgocVinhIT

## Nội dung

Trong kho lưu trữ có:

- File đuôi **`.md`** là **đề bài**
- File đuôi **`.py`**, **`.java`**, **`.cpp`** là **bài giải**
- File theo công thức **`goiy<Tên Bài>.md`** là **file gợi ý cách giải** cho bài đó
- File theo công thức là kienthuc<tên>.text là kiến thức khi học thuật toán

> **Lưu ý:** Chỉ tham khảo cách giải, không được copy. Trong trường hợp quá khó mới copy.
